# Lab08 -- Stima dei parametri, likelihood e simulazione

## Esecuzione

Aprire un terminale nella cartella `Lab08/` ed eseguire:

```bash
pip install -r requirements.txt
python main.py
```

I dati sono già presenti nella cartella `data/`.

Gli script che hanno generato i dati sintetici non sono inclusi nella consegna agli studenti.

## Struttura

- Parte A: MLE per tempi di attesa esponenziali.
- Parte B: likelihood di traiettoria per processo di salto a due stati.
- Parte C: stima di un processo Ornstein--Uhlenbeck discretizzato.
- Parte D: stima simulation-based per SIR parzialmente osservato.
- Parte E: ABC facoltativo, descritto nella dispensa `Lab08.md`.
